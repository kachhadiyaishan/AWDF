# Contributing

Thanks for helping improve the AWDF coursework repository.

## Before making a change

1. Check the root README and the README in the practical or assignment folder you plan to change.
2. Keep each practical or assignment self-contained in its existing folder.
3. Preserve the course exercise's intended requirements; avoid unrelated rewrites.
4. Never commit secrets, populated `.env` files, private keys, dependency folders, or build output.

## Local workflow

1. Fork the repository or create a branch.
2. Make a focused change with clear file names and readable code.
3. Install dependencies only in the relevant project folder(s).
4. Run the project's documented checks and manually verify the changed behavior where practical.
5. Update the relevant README when setup, commands, configuration, endpoints, or behavior changes.
6. Include genuine test output or screenshots when useful. Do not invent measurements or claim a test passed unless it was run.

## Pull requests

A helpful pull request includes:
- A short description of the problem and solution.
- The practical/assignment folders affected.
- Commands run and their actual outcomes.
- Any required environment variables or external services.
- Screenshots for visible UI changes, when applicable.

Keep changes focused and avoid adding credentials, student personal data, or unrelated generated files.
